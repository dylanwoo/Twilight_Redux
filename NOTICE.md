# Attribution

This site is a browser-based tribute informed by two modern recreations:

- [bcaluneo/twilight](https://github.com/bcaluneo/twilight), maintained by
  Brendan Caluneo.
- [joelbraun/twilight](https://github.com/joelbraun/twilight), maintained by
  Joel Braun and adapted for high-DPI PNG output.

Both projects recreate Howard Look's original Twilight wallpaper program for
Silicon Graphics IRIX.

The browser renderer follows the original program's documented visual model:
an orange-to-blue-to-black twilight gradient, deterministic point stars, and
larger cross-shaped stars. High-DPI star scaling, capped 5K star counts, and the
optional diamond star shape are informed by Joel Braun's generator. The
original Silicon Graphics source included in both reference repositories
carries its own permissive copyright and warranty notice.
